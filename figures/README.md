# Representative figures

These seven figures were selected from the original analysis workspace to communicate the workflow and statistical modeling choices without publishing thousands of intermediate plots.

1. `01_atac_da_validation.png` — reprocessed versus published Calderon differential-accessibility estimates.
2. `02_celltype_tfbs_accessibility_heatmap.png` — variable motif-accessibility profiles across immune-cell types.
3. `03_high_vs_low_motif_overlap.png` — selected high-PIP versus low-PIP accessible-motif overlap rates.
4. `04_firth_candidate_forest.png` — adjusted Firth odds ratios and confidence intervals for selected candidates.
5. `05_firth_global_landscape.png` — model-wide Firth landscape across the six final cell contexts.
6. `06_covariate_sensitivity.png` — sensitivity of selected odds ratios to covariate removal.
7. `07_logistic_vs_firth_model_status.png` — ordinary-logistic versus Firth model status/separation behavior.
