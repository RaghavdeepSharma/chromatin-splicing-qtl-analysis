# Representative outputs

The original O2 workspace contained thousands of generated tables. This directory contains compact representative outputs from the statistical workflow.

- `fisher_global_fdr_hits.tsv` — Fisher associations passing global BH-FDR < 0.05.
- `logistic_primary_models.tsv` — compact ordinary-logistic model table with covariate diagnostics and no private development paths.
- `firth_corrected_models.tsv` — final corrected 286 motif × 6 cell-type model landscape (1,716 combinations).
- `final_firth_candidates.tsv` — final Firth associations passing either global or within-cell-type BH-FDR < 0.05.

These are representative research outputs, not a complete data release.
